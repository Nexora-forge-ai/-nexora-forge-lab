# NEXORA FORGE ACADEMY

آکادمی آموزشی فارسی برای یادگیری HTML، CSS و JavaScript با مسیرهای مقدماتی، متوسط و پیشرفته.

## ساختار پروژه

- `index.html`: صفحه اصلی، فهرست دوره‌ها، کلاس درس و محیط تمرین.
- `app.js`: نمایش دوره‌ها و درس‌ها از Supabase، پیگیری محلی پیشرفت و محیط تمرین محدودشده.
- `student-auth.js`: ثبت‌نام/ورود ایمیلی و همگام‌سازی پیشرفت.
- `student.html` و `student-panel.js`: پنل دانش‌آموز و عکس پروفایل.
- `admin.html` و `admin.js`: پنل مدیریت دوره‌ها، درس‌ها، دانش‌آموزان و اطلاعیه‌ها.
- `style.css` و `admin.css`: ظاهر واکنش‌گرا.
- `supabase/academy-v2-final.sql`: ساخت جداول، RLS، نقش‌ها، توابع امن و Storage.
- `supabase/academy-curriculum-324.sql`: کاتالوگ ۳۲۴ درس در ۹ دوره.

## راه‌اندازی Supabase

این پروژه از Supabase زیر استفاده می‌کند:

- Project ref: `nutgcqhcgytjglyuvmla`
- آدرس پروژه و کلید publishable در فایل‌های عمومی وب قرار دارند؛ کلید service_role هرگز نباید در مرورگر قرار بگیرد.

ترتیب راه‌اندازی پایگاه داده:

1. در SQL Editor پروژه جدید، محتوای `supabase/academy-v2-final.sql` را اجرا کن.
2. پس از موفقیت مرحله اول، محتوای `supabase/academy-curriculum-324.sql` را اجرا کن.
3. از صفحه اصلی یک حساب مدیر با ایمیل واقعی بساز و ایمیل را تأیید کن.
4. در SQL Editor، ایمیل مدیر را در دستور bootstrap انتهای فایل اول جایگزین کن و همان دستور را جداگانه اجرا کن. نقش `super_admin` نباید از فرم ثبت‌نام عمومی قابل انتخاب باشد.
5. در تنظیمات Authentication، آدرس دامنه واقعی سایت را در Site URL و Redirect URLs ثبت کن.

**هشدار:** تا وقتی هر دو اسکریپت با موفقیت اجرا نشده‌اند، انتظار کارکرد کامل ثبت‌نام، مدیریت و عکس پروفایل را نداشته باش. اسکریپت دوم ۳۲۴ درس را وارد می‌کند و باید پس از اسکریپت پایه اجرا شود.

## انتشار با Cloudflare Pages

این مخزن یک سایت ایستا است و به فرایند build جاوااسکریپت نیاز ندارد:

- Framework preset: None
- Build command: خالی
- Build output directory: ریشه مخزن (`/` یا `.`، مطابق گزینه‌های داشبورد)
- Root directory: ریشه مخزن

پس از هر commit، اگر اتصال Git در Cloudflare Pages فعال باشد، انتشار خودکار شروع می‌شود. موفقیت commit به‌تنهایی به معنی موفقیت deployment نیست؛ وضعیت آخرین deployment را در Cloudflare بررسی کن.

## امکانات فعلی کد

- مشاهده دوره‌ها و درس‌های منتشرشده از Supabase.
- ثبت‌نام و ورود با ایمیل و رمز عبور Supabase Auth.
- همگام‌سازی تکمیل درس‌ها با `academy_lesson_progress`.
- پنل دانش‌آموز و نمایش پیشرفت دوره‌ها.
- بارگذاری و حذف عکس پروفایل JPG/PNG/WebP تا ۲ مگابایت، در صورت اجرای SQL پایه.
- پنل مدیر با بررسی نقش `admin` یا `super_admin`.
- ایجاد/ویرایش/انتشار/آرشیو دوره‌ها و درس‌ها.
- مدیریت اطلاعیه‌ها و تبلیغات.
- محیط تمرین کد در iframe دارای sandbox.

## مواردی که هنوز تکمیل یا تأیید نشده‌اند

این موارد را نباید آماده و عملیاتی فرض کرد:

1. ورود با شناسه ۱۲ کاراکتری به‌جای ایمیل؛ نسخه فعلی از Supabase Auth ایمیلی استفاده می‌کند.
2. ساخت و مدیریت آزمون‌های واقعی از پنل مدیر و اتصال آزمون صفحه اصلی به تابع نمره‌دهی امن `academy_submit_quiz`. آزمون فعلی صفحه اصلی محلی است و نمره آن در پایگاه داده ثبت نمی‌شود.
3. مسدودسازی/فعال‌سازی حساب دانش‌آموز و بازنشانی رمز از پنل مدیریت.
4. تنظیم SMTP اختصاصی و آزمایش واقعی تحویل ایمیل. کلید یا رمز SMTP را در فایل‌های عمومی قرار نده.
5. آزمایش مرورگری و موبایلی همه ۳۲۴ نمونه‌کد و بررسی APIهای وابسته به HTTPS یا سرویس‌های بیرونی.
6. اجرای واقعی SQL روی پروژه جدید و تأیید RLS، Storage، ورود مدیر و مسیر ثبت‌نام.

## اصول امنیتی

- فقط کلید publishable در frontend استفاده می‌شود.
- کلید service_role یا secret در فایل‌های عمومی یا مخزن قرار نگیرد.
- نقش‌ها فقط با عملیات امن سمت پایگاه داده مدیریت شوند.
- عکس پروفایل هر دانش‌آموز در پوشه شناسه کاربری خودش ذخیره می‌شود.
- کد تمرینی داخل iframe sandbox اجرا می‌شود؛ این محیط جایگزین بررسی امنیتی کد ناشناس نیست.
