HTML چیست؟

HTML زبان نشانه‌گذاری برای تعریف ساختار محتوای صفحات وب است. مرورگر با خواندن تگ‌ها می‌فهمد کدام بخش عنوان، متن یا لینک است.

<h1>سلام دنیا</h1>
<p>این اولین صفحه من است.</p>

نکته: HTML به‌تنهایی زبان برنامه‌نویسی محسوب نمی‌شود؛ ساختار محتوا را مشخص می‌کند.
